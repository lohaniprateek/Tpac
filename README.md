# Branch Overview
The `main` branch is moving fully to `vim.pack` (Neovim ≥ v0.12) as the default, embracing native plugin management.

To keep things flexible, this branch exists for those who still prefer lazy.nvim. It mirrors most of the functionality of main and will continue to stay updated alongside it.

This setup is intentionally kept close to my personal config, so you can:

1. Stick with lazy.nvim if that’s your workflow

2. Or switch to vim.pack when you’re ready

Call it a compatibility layer… or just a safe space before going fully native.
